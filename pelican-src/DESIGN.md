# 鹈鹕骑车 · 设计笔记

主题：一只白鹈鹕戴着头盔、围着布列塔尼条纹围巾，骑着薄荷色城市车，沿海岛环岛公路骑行。
受众：想被逗乐、愿意动手玩一会儿的人。页面的首要任务：让人一眼看到“鹈鹕真的在骑车”，并且想去碰它。

## 配色

| 名称 | Hex | 用途 |
| --- | --- | --- |
| 羽白 | #F4F6F4 | 鹈鹕羽毛、界面文字 |
| 喉囊金 | #F2B33D | 鸟喙与喉囊、界面唯一强调色（选中态、按铃反馈） |
| 深潮 | #12313B | 底部控制条底色（半透明） |
| 液晶 | #C5D3BD / #17231C | 码表反射式液晶屏的屏底与字色 |
| 布列塔尼蓝 | #1F2F5A | 围巾条纹、键盘焦点环 |
| 薄荷车架 | #5FB8A6 | 自行车车架、头盔 |

## 字体

标题竖排宋体（Songti SC / Noto Serif SC），像海边小店的招牌；界面用苹方 / 思源黑体；码表数字用 DIN Alternate 等宽数字，照搬真实自行车码表的气质。

## 自查修正

第一版想法是“深色毛玻璃面板 + 金色强调”，这是任何 3D 演示都会用的默认做法。
改为：右上角做成一台真实的反射式液晶码表（橡胶外框、灰绿屏、深色数字），它本身就是自行车世界里的物件；
其他控件收敛成一条安静的底部条。唯一大胆的地方留给 3D 场景和码表。
